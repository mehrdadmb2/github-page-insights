UNIVERSAL EVENT INSIGHTS v9.1 — D1 CONSOLE ORDER

NORMAL INSTALL:
1) Run EVERY SQL file under INSTALL in filename order.
2) Then run EVERY SQL file under VERIFY in filename order.
3) NEVER run RESET during normal installation.

RESET is destructive and is only for a deliberate clean rebuild.
RESET files are intentionally in a separate folder so they cannot be mistaken for install files.

Do not paste schema-v9.sql into the D1 Console as one multi-statement query.
