BASIC MODE
What happens automatically
Low volume
✓ One request — Basic mode sends one pageview request for each real page load. No polling.
✓ Visitor + session — stable browser IDs are attached to the same request.
✓ IP + geo — the Worker enriches the request with client IP, country, region, city, coordinates, timezone, ASN and network organization when Cloudflare provides them.
✓ Device context — browser, OS, device, vendor/model when available, screen, viewport, pixel ratio, language and connection hints.
✓ Telegram — the same new-visitor event can trigger one detailed Telegram notification; it does not require another browser request.
✓ GitHub + dashboard — the stored event is archived and the dashboard can show the visitor snapshot and event details.
○ Advanced events — clicks, scrolls, visibility events, page-leave and heartbeats are off by default.


ADVANCED
Only enable more when you need it
Advanced mode is optional. Keep the same Worker and platform ID, and enable only the signals you actually need. IP geolocation is already part of Basic mode; browser GPS is different and would require separate user permission, so Basic does not request it.
window.PAGE_INSIGHTS_CONFIG = {
  workerUrl: "https://github-page-insights-worker.game-developer-mb.workers.dev",
  platformId: "my-website",
  platformName: "My Website",
  advancedTelemetry: true,
  trackClicks: true,
  trackScroll: true,
  trackVisibility: false,
  heartbeat: false
};


TELEGRAM
Optional notifications
Admin only
Telegram is separate from website installation. Add the bot token, admin chat ID and webhook secret as Worker Secrets, deploy the Worker, then call /telegram/setup. Use /telegram/test to verify delivery.
